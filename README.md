One line from an agent that "fixed" the bug it shipped — in a branch that only
exists inside its own context window, where everything works perfectly and the
imaginary users have never been happier.

## How it works

`main.ts` writes the single-line excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), using only the Node standard library and no network.
